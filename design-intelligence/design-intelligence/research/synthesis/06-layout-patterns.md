# Layout Patterns Synthesis

## Confirmed structural patterns
- **Two-track rhythm** (Stripe 01): narrow centered column for prose/claims, full-bleed wide blocks for
  demonstration/proof, alternating down the page — the specific mechanism that keeps a very long page
  from feeling monotonous.
- **Bespoke per-project layout, not one template** (Resn 06, A24 16): layout logic is authored per
  major project rather than inherited from a fixed grid, appropriate specifically when a studio's/
  brand's differentiator is demonstrated range.
- **Content-type-driven IA, not one universal template** (Mat Voyce 11): different sections use
  genuinely different layout logic (grid-scan for loose work, linear case-study for formal work) rather
  than forcing one format onto different content types.
- **3D-space-as-layout** (Bruno Simon 07, Iventions 21): the layout unit is literal spatial placement
  within a 3D scene rather than a 2D grid — a distinct, high-commitment pattern appropriate only when
  the underlying concept is genuinely spatial/experiential.
- **Single continuous page with per-section lazy render** (Zajno 09): a specific, named performance-
  aware technique for sustaining a long single-page narrative without front-loading full render cost.

## The recurring judgment call
Layout richness/bespokeness correlates in this set with cases where the layout itself needed to
demonstrate something (range, a spatial metaphor, a specialty) — the more transactional/utility-driven
references in this set (Cowboy 13, the general SaaS-category entries) show comparatively more
conventional, grid-based structure, consistent with `principles/04-grid.md`'s guidance that layout
novelty should be earned by a genuine communicative need.
