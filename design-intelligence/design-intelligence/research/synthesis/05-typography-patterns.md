# Typography Patterns Synthesis

## Confirmed patterns
- **Reserved display treatment, used once per page** (Stripe 01): an italic/distinct display style
  used only for the single most important sentence, never repeated elsewhere on the same page.
- **Type as the entire visual identity, no secondary ornamentation** (By-Kin 10, Mat Voyce 11
  reputation-level): editorial confidence expressed through scale/rhythm/hierarchy rather than color
  or decoration.
- **Type-in-motion as content, not label** (Mat Voyce 11): for a specialist whose actual craft is
  animated type, typography is the primary content unit, not a caption under other content.
- **Technical/schematic typography as brand voice** (Teenage Engineering 15, reputation-level):
  utilitarian, manual-style type treated with the same design rigor as any other brand asset.

## Where evidence is thin
Exact type scales, specific typefaces, line-height, and tracking values are UNKNOWN for the large
majority of this set (no rendered inspection was possible — see `MASTER_PLAN.md` §1). This synthesis
file, and `design-intelligence/typography/` generally, is therefore built more heavily on general,
well-established typographic principle (optical sizing, line-length, rhythm) than on this specific
reference set's measured data. That is stated here rather than papered over with invented numbers.

## The recurring judgment call
Every reference with strong typographic evidence (Stripe, By-Kin, Mat Voyce) ties its typographic
choice to a specific communicative job (mark the one key sentence; support sustained reading; embody
the practitioner's specialty) rather than treating "big type" as inherently premium. This directly
informs `typography/` guardrails against oversized-heading-everywhere patterns — see
`anti-generic-ai/typography-failures.md`.
