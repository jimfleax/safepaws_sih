# Composition

## What it is
How elements are arranged in the frame as a whole — balance, tension, asymmetry, focal points — the
layer above individual element styling.

## When to use asymmetric/tense composition
When the brand goal is energy, creativity, or premium distinctiveness and the audience values visual
interest — see Lusion's deliberate rejection of "gorgeously minimalist" default composition
(`research/awwwards/08-lusion.md` §1) specifically because their brief needed to demonstrate range.

## When to use calm/symmetric/centered composition
Trust-building, transactional, or reading-heavy contexts — see By-Kin's "confident restraint"
(`research/awwwards/10-by-kin.md`) and Cowboy's disciplined, centered product presentation.

## Implementation guidance
- Every composition needs at least one clear focal point at first glance — if the eye can't find
  anywhere to land in the first second, the composition has failed regardless of individual element
  quality.
- Asymmetry should still balance visual *weight* even when it doesn't balance visual *space* — a large
  light element and a small dark element can balance; two large elements of different weight usually
  won't.
- Overlap and layering (elements breaking a grid's edges) read as intentional only when repeated as a
  system across a page — a single overlapping element amid an otherwise strict grid reads as a mistake.

## Failure mode
Composition copied wholesale from a reference without the underlying grid discipline that makes it
work — asymmetry without an invisible structural logic reads as random, not intentional. See
`anti-generic-ai/spacing-failures.md`.

## When NOT to use bold composition
Data-dense interfaces (dashboards, tables, admin tools) where the user's task is fast comparison —
compositional flourish there actively slows the task it should be serving. See `18-dashboard-design.md`.
