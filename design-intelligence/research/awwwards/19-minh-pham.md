## 13. Design Principles Extracted
1. **Give a personal portfolio a real structural conceit, not just a project list** — a formal/personal
   duality (or any other organizing idea specific to the person) turns browsing into an expression of
   identity rather than a database query. Failure mode: a conceit that's cosmetic rather than actually
   restructuring navigation/content ends up as a gimmick layered on a conventional list.
2. **Gesture-based interaction should be an intentional, awarded-quality layer, not default scroll
   behavior** — worth the deliberate design effort specifically when it reinforces the site's core
   concept (as tactile, personal engagement fits a personal-identity-driven portfolio). Failure mode:
   gesture interactions that don't map to any real content relationship, added only for novelty.
3. **Self-awareness about motion-as-embellishment is itself a useful design discipline** — a
   practitioner who can name when motion is compensating for a design that "actually" is less
   interesting is better positioned to catch that pattern before shipping it. Useful as a literal
   design-review question: "if I removed this motion, would the underlying design still hold up?"

## 14. Anti-Patterns
Do not read "fancy motion" as inherently justified by a practitioner's skill — the practitioner's own
words here are explicitly presented as a candid self-critique, not an endorsement; the lesson is to ask
the question he's naming, not to imitate the pattern he's naming as a risk.

It uses structure itself (a formal/personal duality) as a design statement about the designer's own

## 19. Lessons for AI-Generated UI
An AI agent building a personal portfolio should look for a genuine organizing idea specific to the
person (not a generic "About/Work/Contact" default), and should specifically interrogate its own use
of motion with the same question this designer poses of himself: does this animation make the
underlying design better, or is it compensating for a design that isn't actually strong yet?
