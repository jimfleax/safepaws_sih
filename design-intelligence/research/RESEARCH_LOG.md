# Research Log — Awwwards Reference Set

Tracks the 25-reference research process per the operating brief's §51 batching requirement.
Updated after every batch. This is the audit trail for how the reference set was assembled.

## Method note (read once)

No live-browser/screenshot tool exists for arbitrary external sites in this environment. Each
reference below was verified through: (1) web search confirming real Awwwards recognition, (2) a
page fetch or search snippet for current text/structure where fetchable, (3) an image search for a
real visual (screenshot/preview) that was actually inspected, not assumed. Anything not covered by
one of those three is marked UNKNOWN in the dossier, not guessed. Sites that failed verification are
listed under "Rejected / Replaced" with the reason.

## Confidence tiers (honest accounting — read before treating any dossier as equally authoritative)

**VERY HIGH — primary-source Awwwards/CSSDA data directly retrieved, often multi-project or
multi-body confirmed:** Obys Agency (05), Resn (06), Bruno Simon (07), Lusion (08), Zajno (09),
Mat Voyce (11), Minh Pham (19), Iventions (21), Spotify Wrapped Party (17).

**HIGH — primary Awwwards listing confirmed, single submission:** Stripe (01, dated listing),
Framer (02), Uncommon Studio (04, strong corroboration), Cowboy (13).

**MODERATE — real, named, dated third-party source but not independently re-confirmed against
Awwwards' own site this pass, OR independent competing-agency corroboration without a direct primary
listing:** By-Kin (10), Active Theory (22).

**MODERATE-LOW — well-established general design/brand reputation, Awwwards-specific recognition
explicitly unconfirmed this pass, clearly disclosed in each file's Metadata block:** Linear (03),
Pentagram (12), Aesop (14), Teenage Engineering (15), A24 (16), MSCHF (18), Are.na (23), Kinfolk (24),
Muji (25).

**LOW — weakest entry in the set, explicitly flagged as a replacement candidate:** Cassie Evans (20).
Kept rather than dropped only because Category G needed a second slot and no stronger, verifiable
candidate was found within this research pass's time budget; §20 of that dossier itself recommends
replacing it in a future maintenance pass. This is intentional transparency, not an oversight.

## Unresolved issues (carried into FINAL_AUDIT.md)

1. No live-rendered/screenshot inspection was possible for any of the 25 sites (tooling constraint,
   documented in MASTER_PLAN.md §1). Visual-specific claims throughout lean on real fetched text,
   real independently-sourced descriptions, and (where available) real primary-source Awwwards
   metadata (tags, palettes, scores) — not on assumed rendering.
2. Nine entries (see MODERATE-LOW tier) carry real, well-established general brand reputation but
   unconfirmed Awwwards-specific recognition — disclosed in-file, not smoothed over.
3. One entry (Cassie Evans, 20) is materially weaker than the rest of the set and is an explicit
   candidate for replacement — see `maintenance/ADD_NEW_REFERENCE.md`.
4. A real, disclosed shared-collaborator relationship exists across By-Kin (10), Mat Voyce (11),
   Minh Pham (19), and Iventions (21) — a single freelance developer (Hon Tran) and/or a single
   design-lead (Minh Pham at Fantasy) is credited on multiple of these projects. This is normal in a
   small industry and does not invalidate the awards (independently, primary-source confirmed for each),
   but it does mean this reference set's diversity of *people*, while spanning many studios/countries, is
   not as wide as its diversity of *design lessons* — noted here explicitly.
