# Rule: Anti-Generic UI

Applies to: every UI task. This is the operational, always-on version of
`design-intelligence/anti-generic-ai/generic-ui-signatures.md` — read that file for full reasoning.

**Before declaring any UI complete, check for these ten signatures:**
1. Three/four-column feature-card grid as the default for any list of things.
2. Giant heading + subheading + centered CTA + logo strip, repeated as the section template.
3. Meaningless decorative gradients with no brand/content connection.
4. Everything wrapped in a rounded card with a soft shadow, including non-comparable content.
5. Glassmorphism/blur with no real layered content behind it.
6. Identical section spacing regardless of content weight or relationship.
7. Icon-plus-three-words feature blurbs, repeated, none differentiated.
8. Badges/pills/"NEW" tags on nearly everything.
9. Motion applied because the framework makes it easy, with no stated purpose.
10. A visual identity swappable onto a competitor's product with nobody noticing.

**The test to run on every distinguishing decision**: "Could I state, in one sentence, the specific
reason this serves *this* product/brand/audience?" If the honest answer is "it's what these pages look
like," treat that as a failure regardless of which numbered signature it maps to.

**If any signature is present**: don't just remove it — replace it with a decision traceable to
something real and specific about this product, per
`design-intelligence/anti-generic-ai/quality-repair-strategies.md`. Removing decoration without
replacing the interest it was providing just produces a flat page.

"Obviously generic composition" is a named BLOCKER in `design-intelligence/scoring/quality-gate.md`.
